# SLBH
SLBH Website

UI conventions and the shared background contract are documented in [design principles](docs/design-principles.md). New pages inherit the site's local-time background and grain from the root layout.

Image export and storage guidance is documented in [image strategy](docs/image-strategy.md). Run `npm run media:audit` to review asset weight before adding a collection.

The [Metabooks experience audit](docs/metabooks-experience-audit.md) documents the November 2026 redesign reference, including desktop and mobile behavior, measurements, and screenshots.

A separate [landing preview](docs/landing-preview.md) is available at `/preview` when the site is running locally. The existing homepage remains at `/`.
